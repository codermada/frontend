Button Usage Notes

Why buttons matter

Buttons are interactive form controls. They respond to clicks, enabling user-driven actions like entering digits, selecting operators, clearing input, and computing the result.

In this calculator, each button is created with <button type="button"> so the page does not submit any form when clicked.
