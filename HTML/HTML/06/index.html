📦 Span vs Div

Understanding inline and block elements in HTML

Inline Elements - Span

🔹 Span Elements

Span elements are inline elements that flow within text:

inline inline inline

Spans flow horizontally and don't create line breaks.

Block Elements - Div

🔲 Div Elements

Div elements are block elements that create new lines:

block
block
block

Divs create full-width blocks and force line breaks.

Practical Usage

🎯 When to Use Each

Use Span for:

  • Styling parts of text
  • Inline formatting
  • Small content changes
  • Icon placement

Use Div for:

  • Page layout sections
  • Grouping content
  • CSS styling containers
  • Full-width elements
