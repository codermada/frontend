📌 Header Section

This demo uses <div> to represent the page header instead of the semantic <header> tag.

Why use a div for header/footer?

Sometimes you want to demonstrate layout using generic containers. In this example, the top banner and bottom banner are both created with <div> elements.

The page header is styled as a header but remains a non-semantic container. This is useful for learning the difference between structural tags and generic wrappers.

Example content area

Use a <div> to wrap the title and description, while the content itself remains unchanged. The header and footer are still visible and styled like page sections.

Footer Section: This is a footer demonstration using a <div> container instead of the semantic <footer> tag.

Both containers show how generic blocks can still create clear page structure.
